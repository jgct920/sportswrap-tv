SportsWrap.tv Porkbun Upload Package
====================================

This folder is the first upload-ready static website package for SportsWrap.tv.

Upload everything inside this folder to Porkbun Static Hosting:

- index.html
- styles.css
- script.js
- assets/

Important:
- Keep the assets folder next to index.html.
- Do not upload only index.html; the design needs the CSS, JavaScript, and image files too.
- After upload, visit https://sportswrap.tv and https://www.sportswrap.tv if both are enabled.

Suggested Launch Order
----------------------

1. Activate Porkbun Static Hosting for SportsWrap.tv.
2. Upload all files in this folder through Porkbun's editor, file browser, FTP, or GitHub connection.
3. Confirm the homepage loads on SportsWrap.tv.
4. Confirm the logos and hero image appear.
5. Check the site on phone and desktop.
6. Only after SportsWrap.tv is live, update legacy Decibel88.com traffic to redirect to SportsWrap.tv.

Future Updates
--------------

Best long-term workflow:

Use Porkbun's GitHub connection if available on your plan. With that setup, the website files live in a GitHub repository, changes are tracked, and publishing can be as simple as pushing an update.

Simple workflow:

Keep this folder as the master copy. When changes are made, upload the changed files to Porkbun again.

Recommended content to replace next:

SportsWrap.tv Temporary Coming Soon Page
=======================================

Use this package when you want SportsWrap.tv live but hidden behind a simple launch message.

Upload/commit these files to the top level of the GitHub repo connected to Porkbun:

- index.html
- assets/sportswrap-productions-logo.png
- assets/sportswrap-jason-page-logo.png

GitHub repo root should look like:

index.html
assets/

After committing:

1. Wait for Porkbun to republish from GitHub.
2. Open https://sportswrap.tv
3. Hard refresh if needed: Command + Shift + R in Chrome on Mac.

When ready to launch the full site, replace this temporary index.html with the real site files.
